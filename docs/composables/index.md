# Composables

The composables package currently exports WMS-related helpers.

Import from the package:

```ts
import {
  useWmsLayerCapabilities,
  useWmsLegend,
  fetchWmsLegend,
  useWmsCapilities
} from '@deltares/fews-web-oc-composables'
```
